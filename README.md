# Chrome_Home

[下载 ZIP](https://github.com/YeHbtc/Chrome_Home/archive/refs/heads/main.zip) · [单独下载主页](https://github.com/YeHbtc/Chrome_Home/blob/main/Chrome_Home.html)

下载 ZIP 后解压，用 Chrome 打开 `Chrome_Home.html`。只下载主页时，在文件页面点击右上角的下载图标。

主页保留原头像、用户名和默认书签分组。账号验证参数及私人文件夹标识已从对应书签链接移除。书签和外观的后续修改保存在浏览器本地。实时指标需要网络连接。
